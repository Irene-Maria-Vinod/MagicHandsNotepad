# MagicHand 🪄

MagicHand is a computer vision project that uses a webcam to track hand movements and enable touch-free interaction.

## Current Features
- Real-time hand tracking using MediaPipe
- Index fingertip tracking
- Air drawing on a virtual notepad
- Real-time webcam processing

## Technologies
- Python
- OpenCV
- MediaPipe
- NumPy

## How to Run

```bash
python main.py
